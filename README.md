# Из наброска в профессию — сайт курса

Первый блок (обложка) собран **текстом поверх чистой картинки** — всё редактируется,
ничего не «вшито» в изображение.

Живая версия: **https://thereallandlord.github.io/nabroska/**

## Как посмотреть у себя

Двойной клик по **`start.command`** — откроется браузер с сайтом.
(Просто открыть `index.html` двойным кликом нельзя: браузер в этом режиме
не подгружает шрифты.)

## Что где лежит

```
index.html      ← весь текст обложки, правится прямо здесь
css/style.css   ← размеры, координаты, анимации, мобильная раскладка
fonts/          ← Aquarelle + Champagne & Limousines (Regular и Bold)
img/            ← фон без текста (webp + jpg, две ширины)
_reference/     ← исходники: макет с текстом и оригинал картинки.
                  В репозиторий НЕ выложены и не нужны сайту.
```

## Как это ведёт себя на экранах

- Первый блок всегда **ровно в высоту устройства**, прокрутки внутри него нет.
- Картинка заполняет экран целиком.
- **Горизонтальный экран** — текст лежит на макете 2560×1440, вписанном в экран.
  На пропорции 16:9 совпадение с исходным макетом пиксельное.
- **Вертикальный экран (телефон, планшет)** — включается своя раскладка:
  текст сверху, иллюстрация снизу, кадр подобран на героиню.

## Как менять текст

Всё в `index.html`, внутри `<section class="hero">`:

- заголовок — четыре кусочка: `Из`, `наброска`, `В`, `профессию`
  (первые в каждой паре — рукописный шрифт, вторые — обычный);
- описание — блок `hero__lead`, каждая строка в своём `<span class="ln">`;
  пустой `ln--gap` — это отступ между абзацами;
- цифры — блок `hero__facts`;
- кнопка — `hero__cta` (текст и ссылка `href` там же).

## Как двигать текст

В `css/style.css`, блок «ПЕРВЫЙ ЭКРАН». Все числа — **пиксели макета 2560×1440**,
ровно как в исходном файле. Например:

```css
.t-word--nabroska { left: calc(824 * var(--u)); top: calc(248 * var(--u)); }
```

`695` — по горизонтали, `248` — по вертикали, `font-size` рядом — кегль.
Пересчитывать под другие экраны не нужно, всё тянется само.

Одна поправка к макету: весь левый столбец сдвинут на 129 px левее,
а цифры справа — на 20 px правее, чтобы поля по краям были одинаковые.
Вертикальные координаты и кегли — как в макете.

## Анимация появления

Блок «АНИМАЦИЯ» в том же файле. Рукописные буквы «пишутся» слева направо,
остальное мягко всплывает с расфокуса. Очерёдность — в самом низу блока,
одно число на элемент:

```css
.t-word--nabroska { --d: .50s; }   /* когда появляется */
```

Появление стартует после загрузки шрифтов, иначе текст успевает моргнуть.
Если в системе выключены анимации — всё показывается сразу.
