# Из наброска в профессию — сайт курса

Первый блок (обложка) собран **текстом поверх чистой картинки** — всё редактируется,
ничего не «вшито» в изображение.

## Как посмотреть

Двойной клик по **`start.command`** — откроется браузер с сайтом.
(Просто открыть `index.html` двойным кликом нельзя: браузер в этом режиме
не подгружает шрифты.)

## Что где лежит

```
index.html      ← весь текст обложки, правится прямо здесь
css/style.css   ← размеры и координаты (блок «ПЕРВЫЙ ЭКРАН»)
fonts/          ← Aquarelle + Champagne & Limousines (Regular и Bold)
img/            ← фон без текста (webp + jpg, две ширины)
_reference/     ← исходники: макет с текстом и оригинал картинки.
                  Для сайта не нужны, при публикации папку можно удалить.
```

## Как менять текст

Всё в `index.html`, внутри `<section class="hero">`:

- заголовок — четыре отдельных кусочка: `Из`, `наброска`, `В`, `профессию`
  (первые два слова — рукописный шрифт, вторые — обычный);
- описание слева — блок `hero__lead`, перенос строки = `<br>`;
- цифры справа сверху — блок `hero__facts`.

## Как двигать текст

В `css/style.css`, блок «ПЕРВЫЙ ЭКРАН». Все числа — это **пиксели макета 2560×1440**,
ровно как в оригинальном файле. Например:

```css
.t-word--nabroska { left: calc(824 * var(--u)); top: calc(248 * var(--u)); }
```

Поменять `824` → сдвинуть слово по горизонтали, `248` → по вертикали.
Кегль меняется там же (`font-size: calc(134 * var(--u))`).

Блок целиком пропорционально тянется под ширину экрана — специально пересчитывать
ничего не нужно.
